# แผนทดสอบส่งงาน

1. เปิดเว็บ Demo และตรวจรหัสตัวอย่าง → สถานะมีผลใช้งาน
2. ค้นหารหัสที่ไม่มี → ไม่พบใบรับรอง
3. เชื่อม Wallet จำลอง เข้า Admin → สร้างหลักสูตรใหม่
4. ออกใบรับรองใหม่ให้ Wallet จำลอง → ยอดรวมเพิ่ม และพบในใบรับรองของฉัน
5. ออกรหัสเดิมอีกครั้ง → ถูกปฏิเสธ
6. ดาวน์โหลด JSON → เปิดที่หน้าตรวจสอบ → Hash ตรง และแสดงชื่อผู้รับ
7. ทำสำเนา JSON แล้วแก้ recipientName → ขึ้นข้อมูลไม่ตรงกับหลักฐาน
8. ดาวน์โหลด QR → อัปโหลดภาพ QR ที่หน้าตรวจสอบ → พบสถานะทะเบียน
9. แนบ PDF ขณะออกใบรับรอง → ใช้ PDF เดิมตรวจ → Hash ตรง; เปลี่ยนไฟล์ → Hash ไม่ตรง
10. เพิกถอนใบรับรอง → ขึ้นเพิกถอน และยังปรากฏประวัติในทะเบียนและ Wallet
11. ปิดหลักสูตร → ไม่ปรากฏในรายการสำหรับออกใบรับรองใหม่
12. พิมพ์ / Save as PDF → มีชื่อ หลักสูตร วันที่ รหัส และ QR ไม่มีเมนูเว็บไซต์
13. Deploy ผ่าน Remix บน Sepolia → เชื่อมเว็บ → ทำข้อ 3–12 โดยยืนยันธุรกรรมใน Wallet
14. ใช้ Wallet ที่ไม่ใช่ Admin/Issuer → ออกและเพิกถอนไม่ได้ แม้เรียก contract โดยตรง (มี automated test)
15. มอบ Issuer ให้ Wallet อื่น → ออกได้ แต่เพิกถอนไม่ได้; ถอนสิทธิ์ → ออกไม่ได้อีก
16. เปลี่ยนบัญชีหรือ chain ใน MetaMask → เว็บยกเลิกการเชื่อมต่อ ให้เชื่อมต่อใหม่

การทดสอบกล้องต้องอนุญาต camera และใช้ HTTPS/อุปกรณ์ที่รองรับ หากไม่ได้อนุญาต สามารถอัปโหลดภาพ QR แทนได้
